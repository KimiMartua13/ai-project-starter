# 📋 Manajemen Fitur Tambahan (Feature Board)

Dokumen ini adalah papan kerja (*task board*) terpusat untuk mencatat, melacak, dan mengelola penambahan fitur baru atau permintaan perubahan (*Change Request*) dari klien pada aplikasi yang sudah berjalan.

Dikelola secara kolaboratif oleh **User** dan **Feature Agent**.
